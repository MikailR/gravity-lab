# Gravity lab

Play it: [mikailr.github.io/gravity-lab](https://mikailr.github.io/gravity-lab/)

A single-page gravity laboratory. Six thousand tracers follow two moving cores. Hold the pointer to attract. Shift-hold to repel. Three scenes: a tidal encounter, a binary, and a collapse.

`index.html` is the whole app. `verify.mjs` checks the simulation invariants.
